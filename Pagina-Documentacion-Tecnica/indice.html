HTML Básico

HTML define la estructura de una página web.

Los elementos se representan con etiquetas.

Ejemplo de encabezado:

<h1>Título</h1>

Ejemplo de párrafo:

<p>Texto</p>
  • Encabezados
  • Párrafos
CSS Básico

CSS se usa para dar estilo a los elementos HTML.

Ejemplo de color:

p { color: blue; }

Ejemplo de fuente:

h1 { font-size: 24px; }
  • Colores
  • Fuentes
JavaScript and Java

JavaScript es un lenguaje de programación para la web.

Java es diferente, más usado en aplicaciones empresariales.

Ejemplo de JavaScript:

console.log("Hola Mundo");

Ejemplo de Java:

System.out.println("Hola Mundo");

  • Java
Accesibilidad

La accesibilidad permite que todos usen la web.

Ejemplo de atributo alt:

<img src="logo.png" alt="Logo">

Ejemplo de roles ARIA:

<nav role="navigation">
